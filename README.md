# CSC584-Group-Project
Biblio-Space: Library Discussion Room Booking
Description: A reservation system for managing high-demand study spaces and presentation labs.

CRUD: Students create bookings; librarians read daily schedules; librarians update room statuses (e.g., block for maintenance); students delete (cancel) bookings.

Business Logic (Quota Enforcement): A business logic algorithm that calculates a student's total booked hours for the current week. If the sum exceeds the university's maximum quota (e.g., 6 hours/week), the system rejects the new booking attempt.
